# Franchise Ledger Data Ingestion Plan

## Phase 1

Historical season-level franchise data.

Required fields:

- franchiseId
- season
- wins
- losses
- winPct
- postseasonReached
- pennant
- championship

## Phase 2

Franchise operating metrics.

- payroll
- attendance
- farm rankings
- prospect rankings

## Phase 3

Daily updates.

- game results
- standings
- rolling momentum

## Source Priority

1. Lahman
2. Retrosheet
3. MLB Stats API
